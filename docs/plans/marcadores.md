# Marcadores locales

Fecha: 2026-10-28.

## Aceptación

- `Ctrl+D` guarda la página activa si la URL es `http` o `https`.
- El fichero es `bookmarks.json` dentro del directorio de runtime (`%LOCALAPPDATA%/UltraBrowser` o `~/.ultrabrowser`). No va al perfil de Qt ni al repositorio.
- El panel Marcadores lista título y, al hacer doble clic, abre la URL en una pestaña nueva.
- Quitar borra esa entrada del fichero.
- La misma URL actualiza el título y no se duplica.
- Limpiar todo no borra marcadores.

## Fuera

Carpetas, etiquetas, importar de otro navegador, sincronización, modo Tor y el instalador.
